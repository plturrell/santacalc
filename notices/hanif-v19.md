# Provenance

`submission.csv` is a modified portfolio of arithmetic programs for Kaggle Santa 2026. This version contains locally verified replacements and uses 136,829 instructions.

Version 19 builds on [Roman Rozen’s IceFire Strong Start, version 63](https://www.kaggle.com/code/romanrozen/santa-2026-icefire-strong-start), whose exported programs replay to 136,900 instructions. IceFire explicitly allows merging its output and documents the upstream contributors. Complementary programs came from [Asterios Panoras’s Elf Programs and Experiments](https://www.kaggle.com/datasets/asteriospanoras/santa-2026-elf-programs-and-experiments). The dataset attributes those programs to his reruns of Atakan Aldemir’s optimizer, and its [companion notebook](https://www.kaggle.com/code/asteriospanoras/santa-2026-best-public-score-dataset-fails) describes the programs as Apache 2.0. Further changes were produced and verified locally. The search also evaluated public traces from [Alex Chilton](https://www.kaggle.com/code/alexchilton/rudolph-the-red-nosed-register-allocator), [Sargis Khachatryan](https://www.kaggle.com/code/avazaku/elf-calc-paired-helpers-and-target-scheduling), and [Nilanjan Saha](https://www.kaggle.com/code/nilanjansaha123/best-of-public-elf-optimizer).

Version 18 uses the public export from [Sargis Khachatryan’s Paired Helpers and Target Scheduling, version 6](https://www.kaggle.com/code/avazaku/elf-calc-paired-helpers-and-target-scheduling), which replays to 137,708 instructions. Sargis credits [Roman Rozen’s IceFire version 60](https://www.kaggle.com/code/romanrozen/santa-2026-icefire-strong-start?scriptVersionId=371566260) as the starting portfolio and records its upstream lineage. The local search used the prior portfolio, IceFire, and candidate traces from [Nilanjan Saha’s Best-of-Public Elf Optimizer, version 32](https://www.kaggle.com/code/nilanjansaha123/best-of-public-elf-optimizer). The release includes further locally verified shortening.

Version 17 uses the public CSV from [Roman Rozen’s IceFire Strong Start, version 53](https://www.kaggle.com/code/romanrozen/santa-2026-icefire-strong-start), which replays to 137,770 and explicitly permits merging its output. Two shorter programs came from [Asterios Panoras’s Elf Programs and Experiments](https://www.kaggle.com/datasets/asteriospanoras/santa-2026-elf-programs-and-experiments). His [companion notebook](https://www.kaggle.com/code/asteriospanoras/santa-2026-best-public-score-dataset-fails) describes the programs as Apache 2.0 and the dataset attributes those two rows to his rerun of Atakan Aldemir’s optimizer. The local search evaluated [Pratham Jain’s Exact Portfolio Frontier, version 19](https://www.kaggle.com/code/kindasomethin/santa-2026-exact-portfolio-frontier-137770) and earlier IceFire and Frontier traces. IceFire and Exact Portfolio Frontier record their upstream contributors in their own notices.

Version 16 combines the previous portfolio, locally verified refinements, and the public export from [Roman Rozen’s IceFire Strong Start, version 18](https://www.kaggle.com/code/romanrozen/santa-2026-icefire-strong-start). That export replays to 138,441 instructions and its notebook explicitly permits combining the programs. Earlier local refinements used [Bikram Basnet’s Arithmetic Graph Rewrites, version 13](https://www.kaggle.com/code/bikrambasnet1/santa-2026-arithmetic-graph-rewrites). The latest local search also evaluated candidate traces from [Mizero Lucky Gall’s Best-of-Public Merge & Polish, version 7](https://www.kaggle.com/code/mizeroluckygall/elf-calculator-best-of-public-merge-polish). IceFire’s upstream notices include [Exact Portfolio Frontier](https://www.kaggle.com/code/kindasomethin/santa-2026-exact-portfolio-frontier-138441) and the other sources documented in IceFire’s credits.

Version 15 combines the previous portfolio with the Apache 2.0 notebook outputs from [Bikram Basnet’s Arithmetic Graph Rewrites, version 12](https://www.kaggle.com/code/bikrambasnet1/santa-2026-arithmetic-graph-rewrites?scriptVersionId=371348152) and [Roman Rozen’s IceFire Strong Start, version 16](https://www.kaggle.com/code/romanrozen/santa-2026-icefire-strong-start?scriptVersionId=371341996). Their outputs replay to 138,599 and 138,609 instructions, respectively. The final portfolio includes further locally verified shortening. Bikram’s version 12 carries forward the [version 9 source credits](https://www.kaggle.com/code/bikrambasnet1/santa-2026-arithmetic-graph-rewrites?scriptVersionId=371332379) and credits Atakan Aldemir and Roman Rozen for additional recipes. IceFire records its upstream program sources in its notebook.

Version 14 uses the public CSV exported by [Suka’s 139,089 Verified Portfolio, version 3](https://www.kaggle.com/code/skagumire/santa-2026-139-089-verified-portfolio?scriptVersionId=371283044), released on Kaggle under Apache 2.0. Its exported CSV replays to 139,089 instructions. The source notebook credits public program banks and reports 576 programs from its own searches. The files in this dataset include changes from combining verified programs and shortening them locally.

The local comparison portfolio builds on version 13 and the Apache 2.0 output from [Bikram Basnet’s Arithmetic Graph Rewrites, version 8](https://www.kaggle.com/code/bikrambasnet1/santa-2026-arithmetic-graph-rewrites), which replays to 141,086 instructions. The local refinements also use program traces from [Roman Rozen](https://www.kaggle.com/code/romanrozen/santa-2026-icefire-strong-start), [Sargis Khachatryan](https://www.kaggle.com/code/avazaku/elf-calc-shared-helpers-chain-resynthesis), [Atakan Aldemir](https://www.kaggle.com/code/atakanaldemir/santa-2026-joint-recipes-for-large-puzzles), [Rishabh Bafna](https://www.kaggle.com/code/rishabhbafnaiiitd/combinatorial-arithmetic-synthesis-made-easy), and [konbu17](https://www.kaggle.com/code/konbu17/santa-2026-wider-dictionary-portfolio-163k). Bikram’s version 8 also credits Ertuğrul Özer, Vladislav Lavrentev, Nilanjan Saha, and contributors to the earlier portfolios recorded below.
